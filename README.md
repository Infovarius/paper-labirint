# Лабиринт — игровой ведущий

Локальное браузерное приложение для партии на одном экране. Оно не требует установки зависимостей или запуска сервера.

## Запуск

Откройте `index.html` в современном браузере. Создайте партию, передавайте управление игрокам по очереди и используйте кнопку «Карта ведущего», чтобы показать или скрыть секретную карту.

## Игровые правила

- Лабиринт строится как связная сетка коридоров с одной внешней дверью-выходом.
- Игрок выбирает направление и длину перемещения, либо стреляет / использует динамит.
- Выстрел останавливается о стену или первого игрока; динамит разрушает соседнюю стену.
- Реки замкнуты, несут игрока на три клетки по кругу; после попадания в реку есть две попытки выбраться.
- Телепорты идут парами. Арсенал выдаёт пять патронов и один динамит.
- Игрок побеждает, если вынес настоящий клад через выход.
